Maven Toys  Sales Analysis Dashboard

Project Overview
This project analyzes Maven Toys sales data using Power BI to evaluate business performance and identify useful insights through interactive dashboards.

Objectives
- Analyze sales and profit performance.
- Track sales trends over time.
- Identify top-performing products and product categories.
- Compare store performance.
- Monitor key performance indicators (KPIs).
- Support data-driven business decisions.

Tools Used
- Microsoft Power BI
- Power Query
- DAX

Key Features
- Interactive dashboards and visualizations.
- Sales and profit KPIs.
- Time-based sales analysis.
- Interactive filtering for exploring the data.
