Apartment Rental Data Analysis

Project Objective

This project analyzes apartment rental data to identify pricing trends and differences across locations and property characteristics.

Tools

 SQL Server Management Studio (SSMS)

Analysis

The project includes data cleaning, filtering, aggregation, joins, CTEs, and window functions to analyze apartment prices and property characteristics.

Dataset

Apartment rental dataset.

Skills Applied

 SQL Queries
 Data Cleaning
 Aggregate Functions
 JOINs
 CTEs
 Window Functions
